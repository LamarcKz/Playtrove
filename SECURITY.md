# Security

If you find a security problem in Playtrove, please **don't open a public issue**. Report it privately on the [Security tab](https://github.com/LamarcKz/Playtrove/security/advisories/new) ("Report a vulnerability"), so it can be fixed before anyone else knows about it.

Only the latest version gets security fixes. The app updates itself, or you can download the newest version from [Releases](https://github.com/LamarcKz/Playtrove/releases/latest).

---

Se você achar um problema de segurança no Playtrove, **não abra uma issue pública**. Avise em particular pela [aba Security](https://github.com/LamarcKz/Playtrove/security/advisories/new) ("Report a vulnerability"), para que ele seja corrigido antes de mais alguém saber.

Só a versão mais recente recebe correções de segurança. O app se atualiza sozinho, ou dá para baixar a versão mais nova em [Releases](https://github.com/LamarcKz/Playtrove/releases/latest).
